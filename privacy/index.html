隱私權政策

最後更新：2026 年 8 月 25 日

本政策說明 KennyG Cake 的公開 Threads 搜尋與人工商務開發輔助工具如何處理資料。工具僅供授權人員搜尋公開內容、評估可能的合作對象，並由人員自行決定是否聯絡。

我們處理的資料

  • 使用者主動輸入的搜尋關鍵字。
  • Meta Threads API 回傳的公開貼文資料，例如公開帳號名稱、貼文 ID、永久連結、文字摘要、時間與媒體類型。
  • 在 Meta 允許且權限核准時，公開個人檔案資料，例如顯示名稱、公開自介、追蹤者數與驗證狀態。
  • 基本技術紀錄，例如請求時間、結果數與錯誤狀態，用於安全及故障排除；不記錄 access token。

使用目的與法律基礎

資料只用於搜尋公開 Threads 內容、辨識可能的台灣微型團購合作對象、避免重複評估，以及維護服務安全。搜尋結果只作內部人工評估，不用於自動化私訊、留言、發文、按讚或追蹤。

Meta access token

Threads access token 僅儲存在受控的伺服器端祕密儲存空間，用來向官方 Meta Threads API 驗證唯讀請求。Token 不會送到瀏覽器、不會顯示給使用者、不會寫入公開原始碼或操作紀錄。

保存與刪除

一般搜尋回應只在提供畫面結果所需的短暫期間處理，不建立永久全文資料庫。經人工選定的候選紀錄只保存完成合作評估所需的最短時間，至少每 90 天檢查一次；不再需要時即刪除或去識別化。經核實的刪除請求會在 30 天內完成，法律另有要求者除外。

分享與跨境處理

我們不出售公開 Threads 資料。資料可能由 Meta 及必要的基礎設施服務商依其服務條款處理；除維運服務所需、法律要求或取得當事人同意外，不會向其他第三方揭露。

安全措施

我們採用伺服器端祕密管理、最小權限、輸入驗證、速率限制、HTTPS 與不含憑證的錯誤紀錄。只有經授權的人員可使用 reviewer demo 及內部結果。

你的權利
